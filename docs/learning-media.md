# 教材の動画とブランド素材

- 短い実例はHTML videoで直接表示。controls/playsinline/preload=none、内容に一致するposterを設定。自動再生しない。
- 長い無料解説はYouTube埋め込みを選択肢とする。privacy-enhanced modeを使い、限定公開をアクセス制御とは扱わない。
- Instagram埋め込みは公開投稿の紹介に使う。教材の必須説明を外部投稿だけに依存させない。
- 動画数・転送量が増えた時点で専用動画配信へ移す。有料教材は認証と視聴権限の設計を別途行う。公開MP4とYouTube限定公開は保護方式ではない。
- タコ先生のサンプルは納品記録と同一SHA-256の制作プレビュー。正本はDrive、教材用ファイルは変更せず配信。出典はtako-example-sources.json。

公式参考:

InstagramマークはMetaの公式Logo pack（IG_brand_asset_pack_2023.zip）のGradient Glyph SVGを無改変で使用。
出典 https://www.meta.com/brand/resources/instagram/instagram-brand/
ブランドの提携や公式講座を示すものではない。ブランド名を示すコースのアイコンに使用。
