# 公開範囲と確認

## 現在公開できる範囲

講座の構成・公開サンプル、note記事への入口、メンタリングの価格案内、Cal.comの初回相談予約。
初回30分無料、単発30分3,000円（通常予定5,000円）、月額30分×4回10,000円（通常予定20,000円）。
月額にチャット相談を含める。通常予定価格は過去価格ではない。
有料販売は未開始と明記。サンプル本文は公開情報として扱う。

## 表示と操作

共通ヘッダーはLearn内でsticky配置。幅や文字サイズに応じた高さをレイアウトに反映し、固定高さに依存しない。
コース一覧は3列・2列・1列、料金は2列・1列。小画面では検索ラベルと入力欄を縦並び。
主要ボタン44px以上、入力文字16px、キーボードフォーカス、本文へのスキップリンク、動きを減らす設定に対応。
学習画面は小画面で章リストを上部に置き、レッスン選択後に本文へ移動。
今回の検証はソース・ビルド・リンク検査。実機や各ブラウザーでの全ページ検証を完了したとは扱わない。

## 検証コマンド

`pnpm check` → `pnpm build` → `pnpm check:publication` → `pnpm test:payments`。
公開対象に内部リンク切れ・ローカル画像欠落・タイトル欠落がないことを確認する。
既知のCal.com埋め込みコードにクラス変換提案1件。エラーではない。
サンプル／テスト画面はnoindex。主要公開ページをサイトマップへ掲載。

## 有料販売前の残作業

`docs/payments.md`参照。サイト用のStripeキー、正式商品設定、実決済テスト、購入者認証・受講権、保護された教材配信が必要。
販売者情報・キャンセル／返金条件など、本番の販売条件も確定して掲載する。
本番キーの拒否は解除しない。無料相談の受付と講座販売の準備完了を混同しない。

既存Cloudflare Worker `maepace-site`へ直接デプロイ済み。公開先は https://maepace.com/learn/ 。Gitへのpushは行っていない。主要ページのHTTP 200、存在しないページの404、未設定の決済APIが販売不可を返すことを確認。
Cal.comの既定スケジュールは全曜日00:00〜23:59（America/Vancouver）に変更。連携カレンダーの予定などによる空き枠の除外はそのまま。
