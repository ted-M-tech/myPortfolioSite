# Instagram投稿制作教材

Codex・画像生成・HTMLテンプレート・HyperFramesによる実際の制作を扱う。
原本はsrc/content/lessons/sns-content-*.md。共通の題材はタコ先生。
補助ノート・指定フォルダー・提出メモ・点数評価は設けない。

実制作として確認したもの：0086の問題/答えストーリー、0080の発音比較動画。
キャプチャの出典はtako-example-sources.json。過去キャッシュでなく納品チェックサムで照合。
教材用の依頼例は過去の操作ログとして表示しない。
0033の既存8枚カルーセルを制作サンプルとして追加。ギャラリーは動画・ストーリー・カルーセルを同一ページで切替。公開済みInstagram投稿とは表記しない。Codex操作キャプチャは未収録。
画像生成モデル名は使用画面または実行記録の確認後に確定する。

対象ツールはClaude CodeまたはCodex。教材の操作実演と画面はCodexに統一する。機能・画面が同一だと説明しない。CodexネイティブアプリはCUAアクセス禁止のため、ユーザー提供の実キャプチャを待つ。架空の操作画面で代替しない。
